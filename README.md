# DevTrace-NLP 🔍
### NLP-Based Developer Activity Analysis

DevTrace-NLP is a demo project that explores how **Natural Language Processing (NLP) and Machine Learning** can be used to analyze developer activity through Git commit messages.

The project demonstrates how textual commit data can be processed, converted into meaningful features, and analyzed to identify patterns in software development activity.

## ✨ Features

- 📊 **Git Commit Analysis** — Analyze Git commit messages and developer activity.
- 📝 **Text Preprocessing** — Clean and prepare commit messages for NLP analysis.
- 🔤 **TF-IDF Feature Extraction** — Convert text into numerical features for machine learning.
- 🤖 **Machine Learning Analysis** — Apply ML techniques to explore patterns in commit data.
- 📈 **Performance Metrics & Visualizations** — Present analytical results through charts and metrics.
- 🖥️ **Interactive Demo** — Explore the analysis using a Streamlit interface.

## 🛠️ Tech Stack

- **Language:** Python
- **NLP:** Text preprocessing and TF-IDF
- **Machine Learning:** Scikit-learn
- **Data Processing:** Pandas, NumPy
- **Web Interface:** Streamlit

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone <your-repository-url>
cd DevTrace-NLP
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal to access the interactive demo.

## 📂 Project Overview

The project follows a basic NLP workflow:

1. Collect or load Git commit data.
2. Preprocess commit messages.
3. Extract text features using TF-IDF.
4. Apply machine learning techniques.
5. Evaluate results and visualize the analysis.

## 🎯 Objective

The main objective is to demonstrate how NLP and machine learning can support the analysis of software engineering data, particularly Git commit messages and developer activity patterns.
