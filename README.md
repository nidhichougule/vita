# DevTrace-NLP 🔍

**NLP-Based Developer Activity Analysis**

DevTrace-NLP is a demo project that uses **Natural Language Processing and Machine Learning** to analyze developer activity and Git commit data.

### ✨ Features

* Git commit data analysis
* Text preprocessing & NLP
* Feature extraction using TF-IDF
* ML-based analysis
* Performance metrics & visualizations
* Interactive demo

### 🛠️ Tech Stack

**Python • NLP • Scikit-learn • Pandas • NumPy • Streamlit**

### 🚀 Run Demo

```bash
pip install -r requirements.txt
streamlit run app.py
```
